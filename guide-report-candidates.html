阿武隈OS 業務の考え方 — 区分の意味・候補理由・次のアクション
≡ メニュー
この画面の目的

「この異常は国（産業保安監督部）に報告が必要か？」を電気主任技術者が最終判断するための一次スクリーニングリストです。

⚠ よくある誤解
  • このリストに載っていても、自動的に法令報告義務が発生するわけではない
  • 「報告候補」 = 「条文を確認して主任技術者が判断すべき案件」
  • 最終判断は必ず電気主任技術者が行う（システムは候補を提示するだけ）

📌 いつ開くか

  • 朝会で「重大アラームあり」「停止影響あり」の案件を確認するとき
  • 主任技術者が「これ報告要るかな？」と思ったとき
  • 初動トリアージで法令報告フラグが立ったとき（triage.htmlからリンクあり）
  • defect-rca.html で法令分類（A〜F）を設定したとき

🔤 区分（法令分類 A〜F）の意味

電気関係報告規則・保安規定にもとづく分類。異常判断画面（defect-rca）で設定します。

A
重大事故（法令報告必須）
感電死傷・火災・主要電気工作物の損壊による広域停電。報告義務あり。
✅ 速報：覚知から24時間以内 / 詳報：30日以内
B
重要設備故障（主任判断）
発電機・変圧器・主回路など主要設備の重大な損壊。報告要否は主任判断。
✅ 主任確認が必要
C
設備異常（記録・是正）
運転に影響するが法令報告対象外の設備不具合。是正作業票を起票して追跡。
— 法令報告は不要。是正作業票で対応
D
異常検知（監視・様子見）
アラームや測定値の異常だが設備損壊には至っていない。継続監視が必要。
— 作業票は任意。監視記録を残す
E
軽微な不具合
運転への影響が軽微で即時対応不要。記録のみで完結することが多い。
— 記録のみ。必要に応じて予防保全
F
改善提案・その他
異常ではなく改善の余地がある事象。安全上の問題はない。
— 改善検討。作業票は不要なことが多い

🏷 候補理由バッジの意味

要主任技術者確認
安全影響が「高」または「重大」と判定された異常。主任技術者が直接確認してください。
→ 主任が内容を確認し、法令報告の要否を判断する
🚨 報告候補
report_required_flag が手動でONにされた異常。主任技術者が「要確認」とマークした案件。
→ 主任が確認し最終判断を記録する
⚖ 保安規定影響あり
法令分類 A または B が設定されており、保安規定上の報告対象になりうる案件。
→ 電気主任技術者が条文と照合して速報・詳報の要否を決定する
運転影響:停止
発電停止の影響があった異常。停止時間・逸失電力量も記録されている。
→ 停止影響の大きさで報告優先度を判断する

📋 画面の各列の見方

号機
対象風車番号
異常
異常タイトル（省略表示。ホバーで全文表示）
検知日時
異常を最初に検知した日時
区分
法令分類（A〜F）と報告フラグ。上記「区分の意味」を参照
候補理由
この案件が候補リストに上がった理由バッジ
安全 / 運転
安全影響・運転影響の判定値（high=高 / stop=停止）
F判定
リスク評価でF（停止）判定がついた場合に表示
停止(分) / 損失(kWh)
停止記録がある場合に集計表示
作業票
関連する作業票番号。クリックで作業票画面へ
状態
異常判断の現在の状態（open / assessed / closed）
💡 詳細を見るには
行をクリックすると詳細ドロワーが開きます（現時点では defect-rca.html の詳細表示に遷移）。
詳しい内容（根本原因・暫定処置・RCA進捗）は 故障/RCA画面 の該当行をクリックしてください。

▶ 次に何をするか

パターン① A・B分類 → 速報が必要な可能性あり

⚖ 候補リストで確認
→
主任が条文と照合
→
速報（24h以内）
→
詳報（30日以内）

速報・詳報の書式と提出先：産業保安監督部。初動トリアージの「法令期限カウンター」も参照。

パターン② C・D分類 or 要主任確認 → 是正作業票で追跡

⚖ 候補リストで確認
→
法令報告不要と確認
→
📝 作業票を起票
→
✅ 是正作業 → クローズ

作業票が既にある場合は「作業票」列のリンクで確認。なければ defect-rca.html から起票。

パターン③ E・F分類 → 記録確認のみ

⚖ 候補リストで確認
→
軽微・改善提案
→
記録を確認・クローズ

📝 この画面から作業票を起票するタイミング

🤔 迷ったときの基準
「この異常を是正するための作業が必要か？」で判断してください。
状況 作業票 理由
設備を修理・交換する必要がある ✅ 必要 是正作業の指示書として起票
既に作業票がある（一覧に番号あり） — 不要 既存の作業票で管理。重複起票しない
様子見・監視継続（D分類） △ 任意 悪化したら起票。今は記録のみでも可
法令報告だけ必要（A分類） △ 別途判断 法令報告と作業票は独立。設備修理が要るなら起票
改善提案（F分類） — 不要 作業票は不要。安全・異常報告で記録のみ
✅ まとめ
  • 報告候補リスト＝主任技術者が法令報告要否を判断する画面（自動判定ではない）
  • 区分A・Bは速報24時間以内。B以下は主任判断
  • 作業票は「是正作業が必要かどうか」で判断。法令報告と作業票は独立
  • 詳細は 故障/RCA画面 で確認
