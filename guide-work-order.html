≡ メニュー
この業務の目的

是正・修理の作業を「指示書」にして、誰が何をするかを明確化し、実施結果を記録する。

📌 いつ起票：点検で異常発見／アラーム／故障／予防保全で作業が必要なとき。

作業票に書くこと

対象と異常
号機・関連する異常を紐付ける。
処置内容
暫定処置と恒久処置（再発防止）。
結果の記録
停止時間・逸失電力・完了状態。

進め方（手順）

  1. 対象号機と異常（defect）を紐付ける
  2. 作業内容・暫定処置/恒久処置を書く
  3. 優先度・担当を決める
  4. 作業許可（PTW/LOTO）が要るか確認する
  5. 完了後、停止時間・逸失電力・結果を記録する
✓ ポイント
  • 暫定処置で終わらせず、恒久処置（再発防止）まで追う
  • 停止時間・逸失電力を記録すると後の分析に効く
✕ やってはいけない
  • 口頭指示だけで作業票を起票しない
  • 完了報告を空欄のままクローズする
