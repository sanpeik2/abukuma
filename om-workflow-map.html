点検は「発見・記録」、作業は「是正・修理」。両者をつなぐのが点検票 →（異常あり）→ 作業票の流れです。

1点検の種類

種類契機・周期目的計画区分
年次点検年1回（保安規定の周期 ⚑）法定/定期の精密点検。停止を伴うことが多い計画点検
随時点検必要時（台風・落雷後、苦情、要請等）事象に応じた臨時確認非定期
故障点検アラーム／故障発生時故障内容の特定・切り分け非定期（事後）
月次／巡視点検 ⚑月次など日常的な状態監視・外観点検計画点検

※ 種類・呼称・周期は事業所により異なります。上記3種（年次・随時・故障）＋巡視を仮置きしています。⚑ 保安規定の区分に合わせて要調整。

2点検と作業の関係

点検実施 → 点検票に結果記録 → 異常なし＝そのままクローズ ／ 異常あり＝一次評価（A〜F判定）→ 是正が必要なら作業票を起票
  • 点検票＝「何を見て、どうだったか」の記録（証跡）。異常の検知器。
  • 作業票＝「異常をどう直すか」の指示・記録。是正のアクション。
  • 1つの点検票から複数の作業票が出ることも、作業票が点検票を伴わず（SCADA故障等から）直接起票されることもある。

一次評価ロジックは 🧭 考え方フロー図、データの流れは 🔧 異常是正フロー を参照。

3作業票はどんな時に起票するのか

🔧 起票の契機

  • 点検・巡視で異常を発見したとき
  • SCADA/アラームで故障を検知したとき
  • 予防保全（計画的な部品交換・整備）
  • RCAの結果に基づく恒久対策の実施
  • 法令・保安規定に基づく改修・是正

📋 作業票に残る情報

  • 対象号機・作業種別・起票元（点検/SCADA/手動 等）
  • 異常概要・深刻度・優先度
  • 暫定処置 / 恒久処置 / 根本原因（RCA連携）
  • 停止時間・逸失電力（影響）
  • 起票者・起票日時・完了日時（証跡）

4RCA（根本原因調査）の位置づけ

重大・再発・原因不明の異常 → RCA（Root Cause Analysis）を実施 → 恒久対策を作業票の「根本原因／恒久処置」に反映。
  • すべての異常でRCAをやるわけではない。深刻度・再発性でトリガ（A〜F判定で振り分け）。⚑
  • RCA結果は主任が妥当性を確認するのが一般的。⚑

5作業許可証（PTW）と主任許可

🔒 作業許可証（PTW）

  • 危険作業の着手前に発行：高所・電気・LOTO・火気・閉所・揚重 等
  • 作業票に紐づく（1作業票に複数PTWもあり得る）
  • 安全要件（LOTO要否・隔離・風速制限）を明記

🧑‍⚖️ 主任許可（電気主任技術者）

  • 特に電気作業・停止を伴う作業の可否を承認
  • 保安監督の責任者として安全要件の充足を確認
  • 承認/差戻しは証跡（誰が・いつ・コメント）として記録

7法令との関係（誰が・何に基づき起票/承認するか）

電気事業法 → 保安規定（点検義務・周期・電気主任技術者の選任・事故報告義務）
└ 作業者 / O&M が法令(保安規定)に基づき点検・起票を行い、 電気主任技術者 が保安監督・承認を行う。
