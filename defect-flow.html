一次評価の5軸

評価軸低・なし・明確中・あり・推定高・停止・不明 / 多発
安全影響 低 中 高 → 即時停止
運転影響 なし 出力制限 停止
原因明確性 明確 推定 不明 → RCA
再発性 初回 再発 多発 → RCA
保安規定影響 なし 要確認 あり → エスカレ

判定パターン A 〜 F

A
記録のみ
軽微・安全影響なし
条件
  • 安全影響 低
  • 運転影響 なし
  • 原因が明確
  • 初回発生
  • 保安規定影響なし
対応
  • 点検実績に記録・写真添付
  • 次回点検で再確認
  • 必要なら監視項目追加
B
簡易補修
現場で処置可能
条件
  • 現場で安全に補修できる
  • 大きな停止・部品不要
  • 原因が明確
対応
  • 作業票作成
  • 簡易補修・記録
  • 復旧確認・クローズ
C
部品交換
劣化・寿命・破損
条件
  • 部品の劣化/寿命/破損が確認
  • 交換で再発可能性が低い
  • MOCまでは不要
対応
  • 作業票 → 部品手配
  • Permit / KY → 交換
  • 試運転・復旧確認
D
RCA必要
根本原因調査
条件（いずれか該当）
  • 原因が不明
  • 同じ故障が再発・多発
  • 複数風車で同様事象
  • 重大事故の可能性
  • 交換しても再発しそう
対応
  • 暫定措置 → RCA起票
  • 事実整理 → 原因仮説 → 根本原因特定
  • 恒久是正案 → 必要ならMOC
E
MOC必要
変更管理
条件（いずれか該当）
  • 設備設定 / 保護値を変える
  • 点検周期 / 手順を変える
  • 部品型式を変更する
  • 保安規定に影響する変更
対応
  • MOC申請 → リスク評価 → 承認
  • Permit / KY → 変更実施
  • 有効性確認 → MOCクローズ
F
安全・保安規定
即時エスカレ
条件（いずれか該当）
  • 人身災害の恐れ
  • 火災・感電・落下・倒壊
  • 保安規定の停止条件に該当
  • 主任技術者の判断が必要
対応
  • 即時停止 / 制限運転
  • 責任者へエスカレーション
  • 保安規定確認 → 証跡保存

是正の3種類

種類目的具体例
⏱ 暫定是正 安全確保・被害拡大防止 停止、隔離、仮固定、監視強化、出力制限
🔩 恒久是正 根本的な再発防止 部品交換、設定変更、手順変更、点検周期変更
🛡 予防処置（横展開） 同型機・類似設備への対応 他WTG一斉点検、同ロット確認、メーカー照会

AI活用ポイント

⚠️ 大原則：AIは判断を代行しない。 AIは「支援」のみ。最終判断は必ず人間が行い、ai_decisions テーブルに保存する。
🔎
過去類似故障の検索
同じ風車・同じ部品での過去事象を fault_pattern_library・rca_investigations から検索
🧭
RCA要否の参考コメント
一次評価の入力値を元に「RCA推奨」「交換で十分」の参考意見を出力
📝
原因仮説の整理
SCADAデータ・アラーム履歴・過去点検結果から原因候補をリストアップ
🛠
是正案のたたき台
部品交換・設定変更・手順変更の案を提示。人間が選択・修正して確定
🛡
再発防止策の提案
同型機への横展開・点検周期変更・予備品追加などを提案
📋
クローズレビュー要約
是正内容・教訓・フォローアップ事項を自動要約して closeout_reviews に下書き保存
保存先： AI判断は ai_decisions（監査証跡）、コスト・トークンは ai_usage_logs に自動記録
